# Art pipeline

Everything in the city is generated by Blender Python scripts that run headless with the
`bpy` pip module, so no Blender install is needed:

```
python3.11 -m venv /opt/bpyenv && /opt/bpyenv/bin/pip install bpy==5.0.1 pillow
/opt/bpyenv/bin/python tools/blender/build_kit.py   # base kit (sandbox thread)
/opt/bpyenv/bin/python art/tools/build_extra.py     # extra variants, civic, props
/opt/bpyenv/bin/python art/tools/build_specials.py  # special buildings, specials.json, door table
/opt/bpyenv/bin/python art/tools/build_interiors.py # interiors/models/*.glb
/opt/bpyenv/bin/python art/tools/render_previews.py # previews -> art/previews/
/opt/bpyenv/bin/python art/tools/render_interiors.py # room cutaways -> art/previews/
```

Run `build_kit.py` before `build_extra.py`: the extras script imports its helpers.
Both write `.glb` files to `assets/kit/<folder>/`. `scripts/kit.gd` replaces the Blender
materials by name with one shared stylized shader, so only use the material names in
`MAT_COLORS`. `Water` is the only one kit.gd doesn't map yet.

## What's here

| Folder | Contents |
|---|---|
| `buildings/` | `<zone>_<stage>_<size>_<variant>`: r/c/i, stages 1 to 3, size 1 (12 m tile) or 2 (24 m). Variants a to f. |
| `civic/` | fire_station, police_station, school, park, parking_lot (size 1), hospital (size 2) |
| `props/` | lamps, traffic light, trees (round, puffy, pine, cypress, palm), bush, hedge, bench, hydrant, trash bin, mailbox, bus stop, planter, billboard, bollard, news box, power pole |
| `roads/`, `cars/` | road tiles and four car types (base kit) |
| `specials/` | the catalog's special and service buildings with name signs (Second National Bank, The Bunker, power plants...). `art/specials.json` lists id, name, size, tier, tags, model, interior, door spot and triangles. |

## Enterable buildings

`build_interiors.py` writes one glb per room to `interiors/models/`: home, bank (with vault),
bunker, three shops (gas, pawn, diner), nightclub and police station. Each glb has the room
mesh, a `-colonly` collision mesh, `M_<name>` empties for points of interest (spawn, exit,
vault, stash, safe, register, busted, cell_1...) and `L_<rrggbb>_<range>_<energy x10>` empties
that `interiors/interior.gd` turns into lights. `build_specials.py` writes
`interiors/special_doors.gd`, the door spot of every special that has a room.

At run time `interiors/interior_manager.gd` puts a door trigger on each placed special with a
room, fades out, loads that one room high above the map (y 2500, not below: the street
ground is an infinite plane that pushes the player back up) and fades back in. Tests:
`godot --headless --path . --script res://interiors/tests/interiors_test.gd` and
`.../door_e2e_test.gd -- --demo`.

## Budgets for the laptop (Ryzen 5700U, integrated Radeon)

- Small buildings come in at 0.4k to 3k triangles, towers at 3k to 7k, and the two big
  residential towers at 17k to 22k. Props stay under 700. The whole kit is about 145k
  triangles across roughly 90 models.
- No textures. Colour, brick courses and window glow come from the shader, so VRAM cost is
  close to zero and draw calls stay low because every building shares the same few materials.
- LODs: Godot generates them when it imports a glb (`meshes/generate_lods=true` in each
  `.import`). For the mayor view, add `visibility_range_end` on props such as benches and
  hydrants, so they aren't drawn from far above.

## Free CC0 packs

Most CC0 sites (kenney.nl, quaternius.com, polyhaven.com, opengameart, itch.io) are blocked
from the cloud sandbox, and only GitHub is reachable. Kenney's starter kits on GitHub
(City Builder, Racing, Platformer) are CC0, but their toy style doesn't match this kit, so
none are vendored. On the laptop, good picks are Quaternius "Ultimate Modular Men/Women"
and "Universal Animation Library" for people, Kenney "Car Kit" for more vehicles, and
Poly Haven HDRIs for reflections. Keep each one's licence file next to it under `art/third_party/`.
